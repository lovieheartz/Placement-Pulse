Complete Database Entity-Relationship Diagram

Netaji Subhash Engineering College (NSEC)

Database Overview

🗄️ Total Collections

10 Collections - 4 User roles + 6 Application data collections

👥 User Entities

Student, Faculty, HOD, Admin with role-based access control

📝 Application Data

NOC, Notifications, Resume Analysis, Mock Interviews, Tests

🔗 Relationships

One-to-Many and Many-to-Many relationships across entities

💾 Database Type

MongoDB (NoSQL) with Mongoose ODM for schema validation

🔒 Security

Bcrypt password hashing, JWT tokens, email verification

📖 Entity Descriptions

🎓 STUDENT

  • Complete student profile with academic details
  • Skills, certifications, projects, internships
  • Resume management and verification status
  • Social links (LinkedIn, GitHub, Portfolio)

👨‍🏫 FACULTY

  • Faculty member details and credentials
  • Department and designation information
  • Assigned courses and branches
  • Notification sending permissions

👔 HOD (Head of Department)

  • Department head with extended privileges
  • Department-wide student management
  • Faculty creation and test management
  • Department-level analytics access

⚙️ ADMIN

  • System-wide administrative access
  • NOC processing and approval authority
  • User management across all roles
  • Special permissions and super admin role

📋 NOC (No Objection Certificate)

  • Student NOC applications with company details
  • Offer letter upload and processing workflow
  • Status tracking (Pending/Approved/Rejected)
  • Admin remarks and processing history

🔔 NOTIFICATION

  • Multi-type notifications (Simple/Deadline/FormLink)
  • Advanced targeting by role, course, branch, year
  • Deadline management with automatic reminders
  • Read receipts and engagement tracking

📄 RESUME_ANALYSIS

  • AI-powered resume analysis with ATS scoring
  • Text extraction from PDF/DOCX formats
  • Keyword matching and gap identification
  • Categorized suggestions and optimization

🎤 MOCK_INTERVIEW

  • Multi-modal interviews (Text/Voice/Professional)
  • AI-generated personalized questions
  • Question-wise feedback and scoring
  • Performance analytics and improvement areas

📝 APTITUDE_TEST

  • Test creation by HOD/Admin with questions
  • Configurable duration, marks, difficulty
  • Department and course-wise targeting
  • Scheduled test windows with date ranges

✅ TEST_ATTEMPT

  • Student test attempts with answers
  • Auto-evaluation with detailed scoring
  • Time tracking and submission status
  • Performance metrics and analytics

👥 TEST_BATCH

  • Batch-wise test scheduling
  • Department/course/branch grouping
  • Batch statistics and pass/fail tracking
  • Scheduled date management
